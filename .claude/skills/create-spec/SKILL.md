# Create specification
Read CLAUDE.md and relevant product, roadmap, architecture and accepted ADRs. Pick the next unused SPEC ID.
Use docs/specs/_TEMPLATE.md. Set status Draft. Document goal, observable behavior, data/rules, failure cases, tests, exclusions, constraints and open decisions.
Do not invent provider capabilities or pre-approve technologies. Report risks and questions before status Ready. No implementation, commit or push without explicit instruction.
